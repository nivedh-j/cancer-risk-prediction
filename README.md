# 🏥 Cancer Risk Prediction System

> An end-to-end Machine Learning web application that predicts cancer risk based on patient lifestyle and clinical inputs — built with Python, Scikit-learn, and Streamlit.

---

## 🔍 Overview

Cancer Risk Prediction System is an interactive web app that allows users to input key health and lifestyle parameters and instantly receive a **LOW** or **HIGH** cancer risk prediction powered by a trained ML classification model.

This project covers the full ML pipeline — from data preprocessing and model training to serialization and real-time deployment via Streamlit.

## 🛠️ Tech Stack

| Layer | Tools |
|---|---|
| Language | Python 3.x |
| ML Library | Scikit-learn |
| Web App | Streamlit |
| Data Handling | Pandas, NumPy |
| Model Serialization | Pickle |
| Visualization | Seaborn, Matplotlib |

---

## 📋 Features

- 🎯 Predicts cancer risk as **LOW** or **HIGH**
- 🧾 Takes 8 patient inputs: Age, Gender, BMI, Smoking Habit, Genetic Risk, Physical Activity, Alcohol Intake, Family Cancer History
- ⚡ Real-time predictions via an interactive Streamlit UI
- 📦 Pre-trained model loaded via Pickle for instant inference
- ⚠️ Medical disclaimer included for responsible AI usage

## ⚙️ Input Features

| Feature | Type | Range / Values |
|---|---|---|
| Age | Numeric | e.g., 25–80 |
| Gender | Categorical | Male / Female |
| BMI | Numeric | 10.0 – 50.0 |
| Smoking Habit | Categorical | Yes / No |
| Genetic Risk | Numeric | 0 – 1 (or scale) |
| Physical Activity | Numeric | 0.0 – 10.0 |
| Alcohol Intake | Numeric | 0.0 – 10.0 |
| Family Cancer History | Categorical | Yes / No |

---

## 🧠 ML Pipeline

1. **Data Preprocessing** — Handled missing values, encoded categorical features, scaled numerical inputs
2. **Model Training** — Trained and compared classification algorithms
3. **Evaluation** — Assessed using Accuracy, Precision, Recall, F1-Score, and Confusion Matrix
4. **Serialization** — Final model saved using Pickle
5. **Deployment** — Integrated into a Streamlit app for real-time predictions

## 📦 Installation & Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/nivedh-j/cancer-risk-prediction.git
cd cancer-risk-prediction

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run the Streamlit app
streamlit run app.py
```
